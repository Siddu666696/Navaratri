# Photographs

Real temple and event photography is the hero of this design. Drop JPEGs here
using these exact names. Until a file exists, a quiet stone panel is shown in
its place (no placeholder art).

| File                  | Used for                                  | Suggested crop        |
| --------------------- | ----------------------------------------- | --------------------- |
| `temple.jpg`          | Temple reveal scene, social share preview | 3:2, landscape        |
| `day-1.jpg` … `day-10.jpg` | One photo per festival day           | 4:5 portrait (or 4:3) |

Tips
- Export at about 2000 px on the long edge, quality 80-85. Next.js resizes for each device.
- Prefer photographs of the actual alankaram, puja or procession for that day
  (for example `day-3.jpg` = the Kamalarchana, `day-5.jpg` = Deepotsavam).
- Keep a little dark space in the frame; the scene lighting is warm, low-key.
